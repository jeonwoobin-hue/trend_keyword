# deliverables/ — 산출물 관리

프로젝트 이해관계자에게 공유하는 실제 산출물(보고서, 회의록, 발표자료)을 모아둡니다. 코드/설계 문서는
`docs/`, 기획 백로그는 `product/`에 있으므로 이 폴더에는 **완성된 결과물**만 둡니다.

```
deliverables/
├── reports/          # 주간/월간 보고서
├── meeting-notes/    # 회의록
└── presentations/    # 발표자료(pptx, pdf 등)
```

## 파일명 규칙

`YYYY-MM-DD_제목.md`(또는 `.pptx`/`.pdf`) 형식을 권장합니다. 예: `2026-08-10_킥오프_회의록.md`

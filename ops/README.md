# ops/ — 운영 관리

서비스가 실제로 돌아가는 동안 필요한 운영 문서를 모아둡니다. 개발 규칙(`docs/`)이나 기획(`product/`)과
달리, "지금 이 순간 서비스에 문제가 생기면 어떻게 하는가"에 초점을 둡니다.

| 파일 | 용도 |
|---|---|
| [Runbook.md](Runbook.md) | 장애 유형별 대응 절차 |
| [Deployment.md](Deployment.md) | 배포 체크리스트, 환경변수/시크릿 목록 |
| [Monitoring.md](Monitoring.md) | 모니터링 대상 및 임계치 (ADMIN-001 연계) |
| [Incident_Log.md](Incident_Log.md) | 실제 장애 이력 |

인프라/배포 방식이 아직 확정되지 않아 대부분 템플릿 상태입니다. 인프라 결정 및 첫 배포 시점에 채워 넣습니다.

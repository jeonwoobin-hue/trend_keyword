## 1. 문서 개요

### 1.1 목적
본 문서는 사용자의 관심 분야·목적·연령대·선호 플랫폼에 맞춰 급상승 트렌드와 인사이트를 제공하는 웹 서비스 "TrendFit"이 충족해야 할 기능·비기능 요구사항을 정의한다. 마케팅, 콘텐츠 기획, 소비, 시장 조사, 기분 전환 등 다양한 목적을 가진 사용자가 자신에게 최적화된 트렌드 정보를 빠르게 파악하도록 지원하는 것을 목표로 한다.

### 1.2 범위
- 서비스명: TrendFit
- 포함 범위: 이 문서는 TrendFit의 웹 서비스(Streamlit/Dash 기반)를 대상으로 하며, 트렌드 대시보드, 인사이트 리포트, 급상승 알림, 콘텐츠 큐레이션 기능을 포함한다.
- 제외 범위: 관리자 백오피스의 세부 운영 정책(콘텐츠 심의 기준 등)과 유료 결제/구독 과금 체계는 본 문서 범위에서 제외하며 별도 문서로 관리한다.

### 1.3 용어 정의
| 용어 | 정의 |
|------|------|
| 관심사 프로필 | 사용자가 설정한 관심 분야, 목적, 연령대/성별, 선호 플랫폼, 탐색 기간의 조합 |
| Spike Score | 특정 키워드의 검색량·언급량이 평상시 대비 급증한 정도를 수치화한 급상승 지수 |
| 감성 분석 | 키워드와 관련된 게시물·기사의 긍정/부정/중립 여론 비율을 산출하는 분석 |
| 인사이트 리포트 | 선택 조건에 따라 자동 생성되는 최신 이슈 요약 및 키워드 연관성 문서 |
| 게스트 | 비회원 상태로 대시보드 일부를 열람하는 사용자 |
| 세션 | 로그인 후 유효한 인증 상태 |

## 2. 시스템 개요

### 2.1 제품 관점
TrendFit은 네이버/구글 트렌드 API, 유튜브·X 등 소셜 미디어 API, 포털 뉴스 검색 API로부터 데이터를 수집·분석하여 사용자 맞춤형 트렌드 인사이트를 제공하는 독립형 웹 서비스다. 외부 데이터 API에 의존하는 배치/실시간 수집 파이프라인과, 이를 시각화하는 Streamlit(또는 Dash) 기반 프론트엔드로 구성된다.

**시스템 컨텍스트 (텍스트)**
```
[외부 데이터 API: 네이버/구글 트렌드, 유튜브, X, 포털 뉴스]
        ↓ 수집/적재
[분석 서버: 검색량 추이·감성분석·Spike Score 산출]
        ↓ API
[TrendFit 웹 서비스(Streamlit/Dash)] ←→ [사용자]
        ↓
[알림 발송(이메일/인앱)]
```

### 2.2 사용자 클래스 및 특성
| 사용자 유형 | 설명 | 기술 수준 | 주요 목적 |
|------------|------|-----------|-----------|
| 게스트 | 회원가입 전 대시보드 일부를 열람하는 방문자 | 낮음 | 서비스 체험 |
| 일반 사용자 | 관심사 프로필을 등록하고 맞춤 인사이트를 이용하는 회원 | 낮음~중간 | 콘텐츠 기획, 상품 판매 판단, 시장 조사, 기분 전환 |
| 관리자 | 데이터 수집 파이프라인과 사용자를 운영·관리하는 내부 인력 | 높음 | 서비스 안정 운영, 이상 데이터 관리 |

### 2.3 운영 환경
- 플랫폼: 웹 브라우저(Chrome, Edge, Safari 최신 버전), 데스크톱/태블릿 반응형 우선 지원
- 서버 환경: 클라우드 인프라(컨테이너 기반 배포), Streamlit/Dash 애플리케이션 서버 + 별도 데이터 수집/분석 배치 서버
- 네트워크: 안정적 브로드밴드 환경 기준, 외부 API 호출 실패에 대비한 재시도·캐싱 필요

### 2.4 제약사항
- 법적/규제: 개인정보보호법 준수, 외부 플랫폼(유튜브, X, 포털) API 이용 약관 및 크롤링 정책 준수
- 기술적: 외부 트렌드/소셜 API의 호출 한도(Rate Limit) 및 데이터 지연에 따른 실시간성 제약
- 사업적: 초기 출시는 웹 서비스 우선, 분야는 네이버 주제 필터 기준 여행/패션/뷰티/푸드/IT테크 등
  20개 카테고리로 지원

## 5. 외부 인터페이스 요구사항

### 5.1 사용자 인터페이스
- 디자인: 데이터 시각화 중심의 대시보드 UI (Streamlit/Dash 컴포넌트 기반)
- 반응형 웹: 데스크톱/태블릿 우선, 모바일 웹 최소 지원

### 5.2 소프트웨어 인터페이스
| 외부 서비스 | 용도 | 인터페이스 방식 |
|------------|------|----------------|
| 네이버 데이터랩 API | 검색어 트렌드 데이터 수집 | REST API |
| 구글 트렌드(Trends) API | 검색어 트렌드 데이터 수집 | REST API / 비공식 라이브러리 |
| 유튜브 데이터 API | 영상 콘텐츠 및 언급량 수집 | REST API |

| 포털 뉴스 검색 API | 뉴스 기사 수집 | REST API |

## 6. 제약사항 및 가정
- 외부 트렌드/소셜 API의 호출 한도와 데이터 제공 지연은 서비스 실시간성에 영향을 줄 수 있음을 가정한다.
- 초기 버전은 한국어 콘텐츠 및 네이버/구글/유튜브/X/포털 뉴스 데이터 소스를 기준으로 하며, 다국어 확장은 범위 외로 가정한다.
- Spike Score 및 감성 분석 알고리즘은 별도 데이터 분석 모듈 설계 문서에서 상세화한다.

# Prompt_Guide.md — AI 응답/추론 원칙

> 공통 규칙은 [../CLAUDE.md](../CLAUDE.md) 참고. 데이터 관련 추론 규칙은 [Data_Rules.md](Data_Rules.md)도 함께 참고.

## AI 응답 원칙

1. **항상 이유를 설명합니다.** 결론만 제시하지 않고 근거를 함께 제공합니다.
2. **근거 없는 추측은 하지 않습니다.** 데이터/코드로 확인되지 않은 내용은 추측이라고 명시하거나 언급하지 않습니다.
3. **불확실하면 질문합니다.** 애매한 요구사항은 임의로 해석해 진행하지 않고 먼저 확인합니다.
4. **분석 과정도 함께 제공합니다.** 단순 결과만 출력하지 않습니다 (어떤 데이터로, 어떤 방법으로 도출했는지).

## AI 생성 콘텐츠 출력 형식

TrendFit에서 AI가 개입하는 대표 기능:

- **인사이트 리포트 이슈 요약** (FR-REPORT-002): 어떤 키워드/이벤트를 근거로 요약했는지 함께 제시.
  2026-08-18부터 Gemini API(`services/gemini_client.py`, `config.constants.GEMINI_SUMMARY_MODEL`)로
  실제 생성한다 — 프롬프트는 상위 키워드·Spike Score·조회 기간을 근거로 포함하도록 구성
  (`report_service._build_summary_prompt()`). API 키 미설정이나 호출 실패 시 예외를 잡아 기존
  고정 템플릿 요약으로 자동 대체한다(`report_service._build_fallback_summary()`) — 리포트 생성이
  AI 가용성에 좌우되지 않도록 하기 위함(functional-spec.md는 이 실패 모드를 별도로 정의하지 않아
  안전한 기본값으로 자체 결정, 사용자 확인 완료)
- **유사 관심사 비교 추천 키워드** (FR-REPORT-005): 어떤 그룹 비교에서 도출됐는지 근거 명시
- **급상승 알림 문구**: Spike Score 수치와 임계치를 함께 노출해 왜 알림이 왔는지 사용자가 알 수 있게 함

위 기능들은 다음을 반드시 포함합니다:

1. **핵심 결과** — 요약/추천 내용 자체
2. **근거** — 사용된 키워드·지표·기간(예: "최근 7일 언급량 기준")
3. **불확실성 표시** — 데이터가 부족하거나 산정식이 미정인 지표는 그 사실을 함께 안내(예: 감성분석 데이터 부족 시 영역 비활성)

## 프롬프트 작성 시 주의사항

- 프롬프트에 사용하는 지표명은 [KPI_Definitions.md](KPI_Definitions.md)에 정의된 명칭/계산식과 일치시킵니다.
- 사용자에게 노출되는 AI 응답 문구는 전문 용어를 최소화하고 이해하기 쉬운 언어로 작성합니다.
- 외부 API(네이버/구글/유튜브/X/뉴스) 원문을 그대로 재사용/요약할 때는 저작권 및 각 플랫폼의 API 이용약관을
  준수합니다(SRS §2.4 제약사항).
